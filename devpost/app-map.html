1. System Overview

Bulkcart is an AI neighborhood buying agent built for residential societies (RWAs). It aggregates disparate grocery demand across 26+ households, extracts messy multilingual merchant quotes using Google Gemini with structured Pydantic schemas, runs a deterministic Mandi price audit, calculates zero-waste commercial pack distributions, and generates an animated Pakka Bill receipt with counter-offer negotiation text.

3. 4-Stop Code Tour & Implementation Route

Stop 1: Demand Aggregation & Sample Round main.py / data/households.json

What happens: Clicking "Load Sample Round" in the UI fetches /api/sample-round. The endpoint parses data/households.json, aggregating 26 household staple requests (710 kg Rice, 425 kg Atta, 150 L Oil) with raw merchant chat quotes.

Anchor Symbol: get_sample_round() in main.py

Stop 2: LLM Quote Extraction & Fallback Safety services/llm_extractor.py

What happens: Messy quotes written in Hinglish, broken English, and shorthand are parsed into strictly typed Pydantic models (ExtractionResponse) using Gemini 2.5 Flash. If an API key is missing, network fails, or timeout occurs (>10s), it transparently yields data/cached_fallback.json without breaking the demo.

Anchor Symbol: extract_merchant_quotes()

Stop 3: Mandi Benchmarks & Pack Optimizer services/math_engine.py & pack_optimizer.py

What happens: Zero LLM hallucination for numbers. Deterministic Python calculates total retail cost (₹87,020), identifies the lowest verified bidder (₹70,775), stamps 3-state badges (SAHI BHAV, MEHENGA, SAVDHAN), and solves commercial sack distribution with exact 0 kg waste (e.g., 28×25kg + 1×10kg bags).

Anchor Symbol: evaluate_merchant_quotes() and optimize_demand_packs()

Stop 4: Retro Kirana UI & Pakka Bill Slip static/index.html & static/app.js

What happens: Single-page dashboard themed like an authentic Indian Kirana shop with Rozha One typography, rubber-stamp animations, and live counter ticker. Clicking "Approve and send" renders a perforated Pakka Bill receipt with rolling savings (₹16,245) and 1-click counter-offer copy to clipboard.

Anchor Symbol: renderPakkaBill() in static/app.js

4. "To Change This, Start Here"

Add a new commodity (e.g., Dal / Pulses)

Update data/mandi_benchmark.json and data/retail_baseline.json with wholesale/retail rates. In models.py, extend QuoteItem or DemandItem, then add sample demand in data/households.json.

Adjust Mandi Markup Thresholds for Badges

Edit services/math_engine.py lines 45–60: adjust tolerance percentage above Mandi rate for SAHI BHAV (<=15%), MEHENGA (15–30%), or SAVDHAN (>30%).

Modify the Negotiation Counter-Offer Prompt

Inspect EXTRACTION_PROMPT in services/llm_extractor.py. Adjust tone, language preferences (Hindi, Hinglish, English), or payment term requests.

5. A Practice to Reuse: Deterministic Math + Structured AI Boundary

A core challenge in agentic AI development is preventing hallucinations in high-stakes domain calculations (financial ledgers, packaging quantities, contract totals). In Bulkcart, the LLM is restricted solely to unstructured semantic extraction (parsing messy WhatsApp text into typed Pydantic objects). All calculations—benchmark variance, savings percentages, per-household splits, and sack combinations—are strictly handled by pure deterministic Python functions.

Takeaway for future projects: Never ask the LLM to do arithmetic in the prompt. Use the model to normalize unstructured human input into structured schemas, and let deterministic code do the math.
